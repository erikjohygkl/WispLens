WispLens enables scalable, real-time data processing through a decentralized, microservice-based framework platform.

With WispLens, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/WispLens.git`
2. `cd WispLens`
3. Install in editable mode: `pip install -e .`

## Configuration

WispLens is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
